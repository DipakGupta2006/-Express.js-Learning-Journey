This repository contains my Express.js practice projects and mini backend applications built while learning backend development using Node.js and Express.js.

- Express.js fundamentals
- Routing
- Middleware
- EJS templating
- Form handling
- Dynamic rendering

- Query parameters
- Authentication basics

- Router separation
- MVC architecture basics

## 🛠️ Tech Stack

- Node.js
- Express.js
- EJS
- HTML
- CSS
- JavaScript

## ▶️ How to Run

1. Clone the repository

```bash
git clone YOUR_REPOSITORY_LINK
```

2. Install dependencies

```bash
npm install
```

3. Start the server

```bash
nodemon index.js
```

or

```bash
node index.js
```

4. Open in browser

```text
http://localhost:3000
```
